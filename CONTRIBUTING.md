# Contributing

Thanks for your interest in improving this project. The repository is currently at its documentation/foundation stage; contribution instructions will evolve as implementation and tests are added.

## Before opening an issue

- Search existing issues for a similar report or proposal.
- For a bug, include the environment, input format, exact command, expected behavior, actual behavior, and a minimal reproducible example. Remove secrets and private sensor data.
- For a feature, describe the use case and how the change can be validated.

## Pull requests

- Keep changes focused and explain why they are needed.
- Add or update tests and documentation when implementation changes.
- Do not commit credentials, private recordings, large datasets, or model weights without explicit approval and documented redistribution rights.
- Do not claim performance improvements without reproducible measurements and a documented baseline.
